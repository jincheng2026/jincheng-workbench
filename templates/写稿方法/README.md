# 写稿方法

这个文件夹放你的写稿方法：选题卡怎么写、参考怎么拆、叙事怎么定、口播怎么写、改稿建议怎么给，还有你一条条攒下来的判断。

AI 用写稿 Skill（{{Skill}}）帮你写稿、在创作页上给你提修改建议之前，都会先读这里的文件。哪里不合你的习惯，直接改对应的文件，下次写稿就按新的来：不用告诉 AI，也不用重启工作台。

| 文件 | 写什么 |
| --- | --- |
| 01_写稿流程.md | 一条内容从选题到定稿分几步，每一步做完是什么样 |
| 02_选题卡怎么写.md | 选题卡上要写清哪几样 |
| 03_拆参考怎么拆.md | 拿到参考视频的逐字稿以后，怎么拆出能借的东西 |
| 04_定叙事.md | 动笔前怎么定这条讲什么故事、给谁看、解决什么问题 |
| 05_口播通用写法.md | 口播稿的通用写法：开头、节奏、你的语速、收尾 |
| 06_改稿建议怎么给.md | AI 在创作页上给修改建议时要守的规矩 |
| 07_我的判断库.md | 你做过的判断：遇到什么情况、你怎么判断。每条内容定稿后 AI 整理一份清单给你过目，你同意的才记进来 |

这些文件里先放了一份默认写法，照着改成你自己的就行。哪个文件被你清空了，AI 就按写稿 Skill 里最基本的做法来，并告诉你一次。

不想要哪个文件，挪进工作文件夹的「回收站」就行；AI 读不到，就按最基本的做法来。
