# 我的判断库

这里记你自己的写稿判断：遇到什么情况、你是怎么判断的、当时为什么。AI 写稿和给建议之前会读这一页，你记得越多，它写出来越像你。

每条一小节，照这个格式（下面是示例，换成你自己的）：

```
## 遇到开头想先介绍自己的时候 → 先说观众能得到什么，名字放到后面
- 当时为什么：先自我介绍的那两条，前 5 秒就走了很多人
- 哪条内容：T003
- 什么时候不适用：粉丝本来就认识你、点进来就是冲你来的
```

几条规矩：

- 只记你自己确认过的判断。AI 觉得有道理的写法，先当建议给你看，你同意了才写进来。
- 一条只写一个判断。要改一条，就在原来那条上改，写清改在哪天、为什么。
- 和「口播通用写法」冲突时，以这一页为准；拿不准的，AI 先问你。
