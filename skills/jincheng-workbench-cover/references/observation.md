# 观察与归纳方法

## 逐图观察

先读画面，后读作品描述。外部标题只可解释选题，不能替代眼前证据。先总览了解有哪些构图，再逐图在能辨认细节的尺寸查看；抽样不能冒充全样本观察。

每张至少回答下列问题。元素不存在时写「无」，辨认不了时写不确定，不强行补齐：

| 对象 | 需要观察的关系 | 容易写错的地方 |
| --- | --- | --- |
| 可见文字 | 原文、分行、阅读顺序、字面宽窄、粗细、倾斜、字距、描边、硬偏移或柔影 | OCR 结果未经核对；凭字形猜出确切字体；把标题宣传当事实 |
| 主体和角色 | 真人、卡通、产品或场景谁占主位；操作、观察、评论、展示还是只提供尺度 | 有脸就叫主角；把评论者写成事件当事人 |
| 动作 | 谁对什么做什么；手属于谁；视线朝哪；握持、承托、接触或悬浮 | 画外手归错人；掌上悬浮写成握住 |
| 空间 | 镜头的大致方向、前景中景背景、遮挡顺序、近远大小、留白位置 | 头身比例与人物占画面比例混为一谈；前后相同颜色就叫同一层 |
| 文字和主体 | 文字压住哪里；人物是否穿过字；主次阅读怎样衔接 | 把原图自带边框当作平台黑边裁掉 |
| 色彩与材质 | 颜色各自承担什么作用；光照如何整合皮肤、纸、玻璃、金属等 | 未测量就给精确色值；本期产品色当固定品牌色 |
| 内容关系 | 画面已展示了什么；标题还承诺什么；哪些装饰承担主题意思 | 空白屏、工具图标被写成已展示结果 |

检查记录用实际动作描述，例如「已打开原尺寸，查看手与电脑接触处；远处小字仍不可辨」。不能写脚本自动填充的「已逐张放大」。有局部看不清仍可记录其他事实，但受影响的推断不能进入硬性规则。

## 分清事实、解释和建议

合格写法：

- 图中事实：人物托着电脑，屏幕中央只有一个工具图标；纸页围在人物后方。
- 解释：纸页、电脑和标题共同表达资料转换的题材。
- 迁移建议：新题若要强调实际结果，可以使用获准提供的真实成果截图。
- 不确定：纸页上的小字不可辨，不能认定属于某本教材。

不合格写法：「人物展示了工具生成的完整课件。」它把标题的承诺移到了屏幕上。

另一类需要分开的关系：人在桌后看微缩场景，与人缩小后待在场景内部。两图可以同属微缩分支，但主体尺度、视角、灯光和制作所需素材不同，不能合成「人物旁边放一个模型」。

## 从图到规则

1. 为每张写观察，再比较同类与不同类。不能先定「伸掌大头风」，再筛掉不合适的图。
2. 对候选规则明确一个能逐图判断的条件。例如「主标题使用窄字面、紧间距、白色填充」比「统一字体」可检验。
3. 列统计范围、命中、不命中、不可判三组。三组不重叠且覆盖范围。不可判不计作未命中；展示命中数 / 可判数，并同时给出不可判数。
4. 回看每个不命中，判断是另一个分支、边界还是原结论错误。分支中出现得多，不等于全样本固定。
5. 说明统计口径是独立作品还是图片版本。同作品多个封面不能悄悄当成多个作品计数。
6. 对稳定特征保守命名。「该样本反复出现」不等于「作者一直这样做」。单次特殊结构可成为案例，不能靠频次语言包装成规律。

不设统一的「出现超过某百分比即为 VI」阈值。判断还取决于样本数量、时间跨度、题材覆盖、组合特征和反例。置信度只用文字解释：证据充分在哪里，结论还能扩展到哪里。

## 写出辨识度

至少说明一个由多种关系共同构成的识别特征，并让读者点开证据。例如：「细长标题占顶部，人物作为前景评论者，事件由背景的大物件呈现」同时说明文字、角色与内容分工。不要只列颜色、人物和字号。

如果和近似风格对比，必须有实际看过的比较样本。没有比较材料，就说明能在本组看出哪些组合，不编造「别的博主都不这样」。

## 让制作随选题变化

先判断新题要让观众理解的关系：操作过程、成果展示、人物观点、产品细节或情绪场景，再选择对应案例。不是所有工具题都用手托图标，不是所有观点题都让人物亲自做事。

每个复用案例写清：

- 保留：哪些字形关系、尺度关系、层次与阅读顺序建立辨识度。
- 替换：人物、题材物件、文案与哪些背景可以变化。
- 输入：需要身份照片、产品实物、成果截图还是只有文字即可。
- 适用：用什么内容关系判断适合这张参考。
- 失败：例如手与物件接触断开，人物抢过了产品主位，标题替代了画面本应展示的结果。

主体的夸张比例、贴边标题和明显拼贴如果是原作特征，就保留在提取结果中。把它改得更自然、干净属于另外的适配建议。
