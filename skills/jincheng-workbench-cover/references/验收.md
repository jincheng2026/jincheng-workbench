# 验收：每张对照原图和照片检查

每张和它选中的对标原图按相同显示尺寸比一比，再和用户照片比身份。先看整体，再查细节。

| 检查 | 通过时应看到什么 | 不通过写什么 |
|---|---|---|
| 身份 | 认得出是照片里的人，眼镜、五官、发型接近，没有混入对标原图里的人或多余的人 | 「混脸」「不像本人」 |
| 文案 | 文字、数字、大小写、标点准确，没有原图旧词、没有擅自补词 | 写错在哪个字 |
| 手 | 一只一只数：两只手、两条手臂、每只五指，手臂和肩膀连得上，桌上本子边上没有第三只手 | 「三只手」「六根手指」「手臂断开」 |
| 空间 | 原图关键的远近、大小差、遮挡关系仍然成立 | 「空间变平」「主视觉缩成角标」 |
| 动作 | 手臂、手指、接触点、视线协调，人物在做一件具体的事 | 「悬空指」「视线和动作无关」 |
| 遮挡 | 脸、手、头发没挡住标题关键字 | 写挡住了哪个字 |
| 主次 | 标题、脸、主物件在 180 × 240 缩略图里可辨 | 「缩略图看不清标题」 |
| 差异 | 和同批最像的那张至少有两处可见区别 | 「和 03 同构图」 |

写具体问题，不写分数，不写「整体不错」。通过自检不代表用户喜欢，全部候选都留给用户在工作台挑。
