# 交付与验收

完整研究包括：原件与来源、样本清单、逐图观察、稳定特征和变化边界、可制作案例，以及一个图文统一入口。机器可读的记录与文字规范供后续制作读取，HTML 供本人看图判断。使用工具输出时按 [证据格式](evidence.md) 填写数据。

## 页面应能做什么

- 在结论旁看到原图入口，进入对应观察卡后可以放大原图，再返回阅读位置。
- 不扭曲、裁掉、滤色或自动美化来源图片；需要浏览副本时标清它与原件的关系。
- 同时比较两张，查看同类的变化或规则的例外。取消比较后恢复普通浏览。
- 搜索编号和观察文本；没有结果时明确显示空状态。从结论跳图时自动解除搜索遮挡。
- 在同一入口读取规则、案例、全部入选观察与限制，并打开 Markdown 规范。
- 把实际观察与解释、建议分开。界面不能把数据校验通过展示成「作者风格已完全复刻」。

构图示意不是每次必需。只有原图加文字仍难说明空间时再做，使用可关闭的旁图，注明是分析示意，不替代原图。保留主体、动作、接触和前后方向，不凭空加入工具结果。

## 交付前按真实使用路径检查

先执行脚本检查，再用当前宿主允许的浏览器实际操作输出页面。打开后核对首屏和图片；从一个规则点击证据图；放大后关闭；选两图比较；取消其中一张；搜索编号与一个不存在的词；清空搜索；打开文字版。还应查看手机窄窗口或窄面板布局，确保按钮和原图可读。

检查代表图在实际像素与缩略图尺寸下的阅读顺序。若迁移已获授权，逐张核对人物身份、文字、手和物件、实际输出尺寸、同题两张的构图区别；保留所有尝试，不能只展示最好的一张。

## 对外表述必须与证据相称

| 检查 | 能证明 | 不能证明 |
| --- | --- | --- |
| 文件、引用和统计检查 | 图片存在且可读，数量和频次一致 | 图中事实已看对 |
| 逐图事实复核 | 已记录范围内的具体关系与原图相符 | 从此覆盖所有题材 |
| 实际页面操作 | 当前环境能完成查图和对比 | 所有设备都正常 |
| 新选题小样 | 本轮具体选题可以怎样迁移 | 长期稳定成功率或比别的方法更好 |
| 用户明确评审 | 被评审图片获认可或被拒绝 | 未评审图片也已通过 |

未做的项标为未验证。程序自动生成的状态只能说明程序检查结果；「已观察」和「用户认可」必须来自实际动作或反馈。

## 停止或交付部分结果

来源身份冲突先解决对象；无法打开的图片标明数量与位置并停止把它们纳入规律；缺日期影响「最新」结论但不阻止有界的本地样本研究；缺关键局部降低相关结论置信度。交付部分结果时写清已观察数量、总目标数量、剩余项对结论的影响，不能在标题写完整验收。

优质的研究应让没有参加本次聊天的人能选择参考、保留关键关系并判断失败；并不依靠报告页数、固定案例数量或自评分数证明质量。
